# Assets

This directory contains lightweight visual assets for the open-source release.

- `aide-banner.png`: generated README banner showing the AIDE data-curation
  workflow from candidate scientific datasets to organized training-ready data.
- `aide-mark.svg`: deterministic vector mark for compact repository surfaces.
- `paper/`: rasterized Figures 1, 4, and 5 of the paper *Agentic Intelligent
  Data Engine for Scientific Large Language Models* (Xie et al., *Nature
  Communications*, 2026), rendered at 150 dpi from the accepted manuscript.
  These figures are copyright of the authors and are shared under the paper's
  CC BY 4.0 licence; they are not covered by the repository's MIT licence.

The banner intentionally contains no embedded text so that repository title,
badges, and links remain accessible and crisp in Markdown.
